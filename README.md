# Neural Nomad: The Path to Prediction

## How to Run
Due to security restrictions in modern browsers (CORS), you cannot run this directly by double-clicking  because it tries to load .

**Option 1: VS Code Live Server (Recommended)**
1. Open this folder in VS Code.
2. Install the 'Live Server' extension.
3. Right-click  and choose 'Open with Live Server'.

**Option 2: Python Simple Server**
1. Open your terminal in this directory.
2. Run: `python3 -m http.server`
3. Go to `http://localhost:8000` in your browser.

## Features
- **Level 1**: Drag and drop matching game.
- **Level 2**: Interactive Perceptron calculator.
- **Level 3**: Gradient Descent visualizer.
- **Level 4**: MLP Network explorer.
- **Live Brain**: Real-time canvas visualization.
